# AI Trading Journal

A Telegram bot for keeping a trading journal using OpenAI, n8n and Google Sheets.

## About

I built this project to learn workflow automation and AI.

Instead of making another portfolio project, I wanted to build something I could actually use. I already keep a trading journal, so building one myself felt like the right project.

The bot takes a trade description, extracts the important information with OpenAI, saves it to Google Sheets and lets me view basic trading statistics in Telegram.

## Features

- Save trades from Telegram
- Extract trade information using OpenAI
- Store trades in Google Sheets
- View the latest trade
- Show trading statistics
- Calculate Win Rate

## Tech Stack

- n8n
- OpenAI API
- Telegram Bot API
- JavaScript
- Google Apps Script
- Google Sheets
